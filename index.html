FAQ

  1. Launch Fortnite.
  2. Go to Settings → Game → Language and Region → Matchmaking Region → NA East.
  3. Return to the Main Lobby.
  4. Scroll down and select Custom Key.
  5. Enter the tournament code and click Accept.
  6. Select Battle Royale → Zero Build → Solo.
  7. Ready Up.

Everyone needs to be on NA East so they can successfully join the lobby. You may experience higher ping, but NA East is required.

After you Ready Up, you should see the number of players queued. If you see that, just wait for the host to start the match.

First, double-check:

  • You're on NA East,
  • You're using Battle Royale → Zero Build → Solo,
  • You've entered the code correctly,
  • Restart Fortnite and try again.

We'll do our best to help. If you're unable to join, your entry can be rolled over to the next round.
